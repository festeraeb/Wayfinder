### 1️⃣ Snapshots (No Setup Required)

```bash
# Create a snapshot of your work
# In Wayfinder: 💾 Snapshots tab → "Create Snapshot Now"

# Restore if something goes wrong
# Click the restore button on any snapshot
```

✅ **Done!** Your files are automatically backed up every hour.

---

### 2️⃣ GitHub Models API (Optional - 2 min setup)

**What you need:**
- GitHub account (you already have this!)
- Personal Access Token from GitHub (1 min to create)

**Setup:**

```bash
# 1. Go to GitHub settings
# https://github.com/settings/personal-access-tokens/new

# 2. Create token
# Name: "Wayfinder AI"
# Select scope: "Codespaces"  
# Click "Generate"

# 3. Copy the token (github_pat_xxxxx)

# 4. Copy config template to your index directory
cp github_models_config.template.json [YOUR_INDEX_DIR]/github_models_config.json

# 5. Open github_models_config.json and paste your token
```

**Test it:**
```
Wayfinder → ⚙️ Task Decomposer
Enter: "Add caching to improve search speed"
Click: Generate Tasks
→ See 8 concrete tasks with code stubs (generated by Claude or GPT-4o-mini)
```

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Can't create snapshot | Make sure index directory is writable |
| Tasks generation fails | Check your GitHub token in `github_models_config.json` |
| "No config found" | Copy template file and add your GitHub token |
| Rate limit error | GitHub free tier: 15 req/min, wait a minute and retry |

## Security Notes

✅ **Tokens are LOCAL only:**
- Stored in `github_models_config.json` (gitignored)
- Never sent to GitHub without your explicit permission
- Only used to authenticate to GitHub Models API

⚠️ **Keep these LOCAL:**
- Never add `github_models_config.json` to git
- Never share your GitHub token with others
- Never email your token
