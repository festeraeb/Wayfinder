# Wayfinder Deployment Configuration

## Installation
Your production build is ready at:
```
src-tauri\target\release\bundle\nsis\Wayfinder_2.0.0_x64-setup.exe
```

Run this to install Wayfinder on your system.

---

## Configuration Files

After installation, you need to create config files in your Wayfinder index directory:

### 1. Snapshots Config (Optional - works without it)
File: `snapshot_config.json`
```json
{
  "storage_provider": "local",
  "retention_days": 7,
  "max_snapshots": 30,
  "auto_snapshot_interval_minutes": 60
}
```

### 2. GitHub Models API Config (For AI Features)
File: `github_models_config.json`

You need:
1. **GitHub Personal Access Token** - Create one at: https://github.com/settings/personal-access-tokens/new
   - Name: "Wayfinder AI"
   - Scope: `Codespaces`
   - Click "Generate"
   - Copy the token (starts with `github_pat_`)

2. **Fill config:**
```json
{
  "github_token": "github_pat_YOUR_TOKEN_HERE",
  "model": "gpt-4o-mini"
}
```

Replace `github_pat_YOUR_TOKEN_HERE` with your actual token.

---

## First Run

1. Install Wayfinder using the setup.exe
2. Point it to your Wayfinder index directory
3. Create `github_models_config.json` with your GitHub token (if you want AI features)
4. Restart Wayfinder
5. Test: Go to "⚙️ Task Decomposer" → Enter idea → Click "Generate Tasks"

---

## Features

✅ **Snapshots (💾 tab)**
- Automatic backups every hour
- One-click restore
- No configuration needed

✅ **Task Decomposer (⚙️ tab)**
- Break ideas into 8 concrete tasks
- Requires: GitHub token (2 min setup)
- Free (GitHub Models API)
- Models: gpt-4o-mini, claude-3-5-sonnet, gpt-4

✅ **Existing Features**
- File organization
- Classification system
- Move history tracking
- Pattern database
